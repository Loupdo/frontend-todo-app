# TODO-App 📝

A full-stack TODO application with user authentication, task management, and a polished UI.

## 🚀 Main Features

- ✅ User authentication using **JWT**
- 🧾 Create, read, update, and delete **todos**
- ⚙️ Global state management via **React Context API**
- 🧪 Form validation with **Formik + Yup**
- 🔗 API requests handled using **Axios**
- 🎨 Styling powered by **Bootstrap**

---

## 🖥️ Frontend (React + Vite)

npm install
npm run dev

### Tech Stack:
React
Vite
React Router
Formik + Yup
Axios
Bootstrap

## backend
